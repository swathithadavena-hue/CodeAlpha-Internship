# 📸 Image Gallery

A responsive and interactive **Image Gallery Web Application** developed using **HTML, CSS, and JavaScript**. This project was completed as **Task 1** during my **Web Development Internship at CodeAlpha Technologies**.

## 📖 Project Overview

The Image Gallery provides a simple and engaging way to browse a collection of images. It features a responsive grid layout and an interactive lightbox that allows users to view images in an enlarged format. Users can easily navigate between images using Previous and Next controls without returning to the gallery.

The project focuses on building an intuitive user interface while applying JavaScript concepts such as DOM manipulation and event handling.

---

## ✨ Features

- 📷 Responsive image gallery layout
- 🔍 Lightbox image preview
- ⬅️ Previous and Next image navigation
- ❌ Close button to exit the lightbox
- 📱 Mobile-friendly responsive design
- ⚡ Smooth and interactive user experience

---

# 🎵 Music Player

A responsive and interactive **Music Player Web Application** developed using **HTML, CSS, and JavaScript**. This project was completed as **Task 4** during my **Web Development Internship at CodeAlpha Technologies**.

## 📖 Project Overview

The Music Player is a web-based application that enables users to play and manage audio files through a simple and user-friendly interface. It provides essential music player functionalities such as play, pause, previous, next, playlist selection, volume control, and autoplay.

The project demonstrates how JavaScript interacts with the HTML Audio API to create an interactive multimedia experience while maintaining a responsive and visually appealing interface.

---

## ✨ Features

- 🎵 Play and Pause music
- ⏮️ Previous and Next song navigation
- 📀 Display song title and artist name
- 🖼️ Album cover display
- ⏱️ Current playback time and total song duration
- 📊 Interactive progress bar with seek functionality
- 🔊 Volume control slider
- 📋 Playlist with clickable songs
- ✅ Highlights the currently playing song
- ▶️ Autoplay to the next song after the current song ends
- 📱 Responsive design for desktop and mobile devices

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- HTML Audio API
- DOM Manipulation
- Event Handling
- Responsive Web Design
